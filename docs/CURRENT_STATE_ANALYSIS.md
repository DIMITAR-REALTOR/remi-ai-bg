# CURRENT STATE ANALYSIS — REMI AI

Дата: 2026-09-01

Текущ статус
------------
REMI AI е fullstack уеб приложение за българския пазар на недвижими имоти, изградено с TanStack Start (React 19 + Vite). Backend-ът е управлявана PostgreSQL база през Supabase, с RLS политики, ролева система и AI функции през Lovable AI Gateway. Към момента приложението включва: публичен каталог на имоти и брокери, CRM (клиенти, задачи, сделки, ревюта), агенции, инструменти за анализ (риск, пазар, инвестиции, сравнение, чеклист, преговори), договорни помощници и MCP интеграция за агенти. За актуална архитектура, технологичен стек и спецификации виж `README.md` и `CONTEXT.md` в корена на репото.
